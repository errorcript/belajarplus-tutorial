Modul 01 • Engine Internals

Bedah Arsitektur Direct RPC TanStack vs UI Browser Hang

P0 PERFORMANCE FIX

Mengapa bot tidak menggunakan automasi klik tombol di browser (DOM clicking)? Pada platform BelajarPlus v2.0 (dibangun dengan TanStack Router & TanStack Start), memuat modal daftar anggota kelas dan mencentang 400–1000 siswa menyebabkan re-render DOM masif, memicu memory leak, dan tab browser mengalami freeze (hang). Bot bypass langsung mengarah ke server function internal melalui RPC HTTP POST terautentikasi.

❌ Jalur UI Browser Tradisional
  • Buka halaman /master-data/rombel → Klik "Anggota".
  • Modal render 800+ baris DOM siswa sekaligus.
  • Browser lag 15–30 detik; centang manual rawan timeout.
  • Satu kegagalan koneksi membatalkan seluruh operasi (Zero recovery).
⚡ Jalur Bot Direct ServerFn RPC
  • Auth sekali via Playwright / Supabase token (sb-*-auth-token).
  • Kirim HTTP POST ke hash server function /_serverFn/337a3c1a...
  • Kirim header x-school-override: <tenant-uuid> & x-tsr-serverfn: true.
  • 1.000 siswa ter-assign ke rombel masing-masing dalam < 3 detik.

Daftar Hash Server Function Resmi Platform BelajarPlus:

/_serverFn/a30d7ae826e53b88... Query Candidates rombelId, q: "" Mengambil daftar siswa berstatus Belum ditempatkan.
