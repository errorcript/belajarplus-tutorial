🌐 DEFINISI & KARAKTERISTIK MODE STANDAR
Mode Standar adalah mode pengerjaan ujian yang berjalan di peramban web biasa (Google Chrome di Android/Laptop/PC, atau Safari di iPhone/iPad) tanpa mewajibkan aplikasi Kiosk khusus (Belajar Plus Exam / Safe Exam Browser). Mode ini memberikan fleksibilitas tinggi bagi sekolah yang menggunakan perangkat beragam, namun pengawasan integritas dilakukan via pemantauan tab peramban dan pengawasan visual ruangan.

iPhone / iPad (Safari) Penting: iOS akan menjeda JavaScript saat layar mati atau ganti tab. Auto-submit bisa tertunda jika waktu habis saat layar mati. Wajib minta siswa iPhone untuk tidak mengunci layar HP selama ujian berjalan.

2. SOP WAJIB SEBELUM UJIAN MODE STANDAR DIMULAI

  1. Wajib Pakai Google Chrome Resmi: Instruksikan seluruh siswa Android dan Laptop untuk membuka portal melalui Google Chrome resmi terbaru. Dilarang menggunakan browser bawaan HP (Vivo Browser, Xiaomi Mi Browser, UC Browser, atau Opera Mini).
  2. Atur Waktu Tunggu Layar (Screen Timeout): Ubah ke 10 Menit s.d. 30 Menit agar layar tidak mati saat membaca teks soal panjang.
  3. Aktifkan Mode Jangan Ganggu (DND): Agar notifikasi chat dan panggilan masuk tidak mengganggu fokus layar.
  4. Matikan Fitur Bilah Samping / Floating Window: Terutama bagi pengguna HP Realme, Oppo, dan Xiaomi (lihat Bagian 4).

3. TROUBLESHOOTING KENDALA DI MODE STANDAR

Kasus 1: Tampilan Rusak / Logo Raksasa / Tombol Tidak Berwarna (FOUC)

Tampilan
Foto: Tampilan CSS gagal muat di browser HP
Gejala
Halaman ujian terbuka tetapi layout berantakan: logo sekolah raksasa memenuhi layar, font Times New Roman, dan tombol pilihan jawaban berwarna abu-abu polos tidak merespons.
Penyebab:

Siswa menggunakan browser bawaan merek HP yang mengaktifkan fitur Ad-Blocker (Pemblokir Iklan) atau Mode Hemat Data (Data Saver) yang memblokir berkas tampilan (styles.css).

Solusi Cepat:
  1. Salin alamat ujian, buka menggunakan Google Chrome resmi.
  2. Jika sudah di Chrome: matikan mode hemat data atau matikan Ad-Blocker, lalu tarik layar dari atas ke bawah untuk muat ulang (*pull-to-refresh*).

Kasus 2: "Anda berada di luar area sekolah" / GPS Kedaluwarsa

Lokasi
Foto: Notifikasi batas lokasi di HP siswa
Gejala
Muncul notifikasi merah: "Anda berada di luar area sekolah" atau "Lokasi belum akurat atau sudah kedaluwarsa. Aktifkan GPS lalu coba lagi".
Langkah Penanganan:
  1. Di HP Siswa: Aktifkan GPS (Lokasi). Buka aplikasi Google Maps selama 5–10 detik hingga titik biru mengunci posisi dengan akurat.
  2. Buka kembali browser Chrome, pastikan klik "Izinkan" (Allow) saat peramban meminta izin akses lokasi.
  3. Di Sisi Proktor/Admin: Jika banyak siswa di ruang kelas belakang terkena notifikasi ini, buka menu Master Data Sekolah → Pengaturan Lokasi, lalu perlebar radius toleransi menjadi 300 s.d. 500 meter.

Kasus 3: Kirim Jawaban Macet / Berputar di "Penyebab belum diketahui"

Kritis
⚠️ PANTANGAN SANGAT KERAS: JANGAN LOGOUT & JANGAN HAPUS DATA!
Seluruh jawaban siswa 100% AMAN di memori peramban (IndexedDB HP). Keterlambatan terjadi karena antrean submit serentak atau file foto jawaban uraian berukuran besar (4–8 MB/foto) mengalami *upload timeout*.
Langkah Penanganan Lapangan:
  1. Sambungkan HP siswa ke tethering hotspot guru/pengawas yang sinyalnya kuat, lalu tekan tombol "Coba kirim lagi" satu kali.
  2. Jika jam ujian telah habis, minta siswa menekan tombol "Ke dashboard" (siswa boleh keluar ruangan/istirahat).
  3. Bawa HP ke ruang proktor/ruang guru dengan internet lancar. Cukup buka halaman Beranda / Dashboard BelajarPlus di browser. Sistem secara otomatis menjalankan background outbox flush dan mentransfer seluruh lembar jawaban ke server tanpa perlu membuka soal kembali!

4. PENGAWASAN INTEGRITAS KHUSUS MODE STANDAR

Temuan Lapangan: Mode Mengambang / AI di HP Realme, Oppo, Xiaomi

Potensi Kecurangan
Foto: Catatan Tim Trainer Lapangan
Catatan Pengawas Lapangan
"Bagi siswa yg menggunakan HP merk Realme masih bisa di mode mengambang shg masih bisa buka tab lain / AI tanpa terdeteksi pelanggaran".

Pada browser mode standar, sistem operasi ponsel modern (Realme UI, ColorOS, HyperOS) memiliki fitur Smart Sidebar / Floating Window. Siswa dapat membuka jendela pop-up kalkulator, browser mini, atau asisten AI di atas peramban tanpa melepaskan status fokus jendela secara penuh.

Instruksi Wajib Pengawas Ruangan:
  1. Pengawas wajib berjalan keliling dan melakukan inspeksi visual dari arah samping/belakang siswa.
  2. Sebelum ujian, wajibkan siswa menonaktifkan fitur Bilah Samping Cerdas (Smart Sidebar) dari menu pengaturan HP.
  3. Jika terlihat ada aplikasi yang melayang di atas layar, pengawas berhak menegur dan mencatat pelanggaran tata tertib ujian.

5. STATUS ANALITIK PEMBELAJARAN UNTUK PROKTOR (MODE STANDAR)

Foto: Menu Analitik Pembelajaran Proktor

Jika pada menu Analitik Pembelajaran nama siswa muncul di kategori "Perlu Perhatian":

  1. expired_no_receipt (Waktu habis, penerimaan belum terkonfirmasi):
    Sering terjadi pada pengguna iPhone jika layar terkunci saat waktu habis.
    Solusi: Minta siswa membuka kembali lembar ujian di HP yang sama dengan internet aktif → sistem otomatis mengeksekusi auto-submit. Jika HP siswa mati total, proktor klik tombol [Reset perangkat].
  2. finalize_unconfirmed (Finalisasi belum terkonfirmasi):
    Siswa sudah klik Kirim tetapi paket jawaban tertahan akibat sinyal putus.
    Solusi: Hubungkan ke internet lancar, buka kembali halaman ujian, tekan tombol "Coba kirim lagi".
  3. terminated (Sesi dihentikan):
    Siswa melanggar aturan tab melebihi batas toleransi. Jika murni kecelakaan teknis, proktor dapat mengklik [Reset perangkat] agar siswa bisa masuk kembali.
