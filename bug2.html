  2. Gunakan ekstensi auto-fill password atau script programatis untuk mengisi field email dan kata sandi tanpa memicu event input atau change keyboard.

// Di komponen LoginForm: <form onSubmit={(e) => { e.preventDefault(); const formData = new FormData(e.currentTarget); const email = formData.get('email') || emailState; const password = formData.get('password') || passwordState; handleLogin({ email, password }); }} > ... </form>
